# snepbox/addons

All server filesystem addons in one repository.

All non-submodule code is licensed under the AGPL-3.0.  
Any changes you make to these files **must** be published with the original license.

## Installing

1. `git clone https://github.com/snepbox/addons` in your `garrysmod` directory
2. `git submodule update --init --recursive` in your addons directory
